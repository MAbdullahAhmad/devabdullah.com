# devabdullah — coding instructions

- This project is the Abdullah Ahmad portfolio at `devabdullah.com`.
- Do not invent personal experience, projects, employers, metrics, testimonials, education, skills, locations, social profiles, or availability.
- Keep personal content centralized in `content/profile.ts` and project content in `content/work/`.
- Preserve strict TypeScript and the existing design system.
- Before changing Next.js behavior, read the relevant guide under `node_modules/next/dist/docs/`.
- Run `npm run check` after code changes.
- Deployment/CI-CD configuration is intentionally deferred until server details are supplied.
